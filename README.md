#  Online Clothing Store Analysis – Excel Dashboard Project

This Excel-based project provides insights into the sales and performance of an online clothing store. The dashboard enables stakeholders to explore revenue, order trends, customer behavior, and product performance in an interactive and structured format.

---

##  Key Insights & Features

The dashboard includes the following analyses:

- **Sales Overview**
  - Total Sales, Orders, and Average Order Value
  - Monthly and quarterly sales trends
- **Product Analysis**
  - Top-selling categories and items
  - Product return and discount trends
- **Customer Insights**
  - Repeat customer rate
  - Customer segments and lifetime value (CLV)
- **Geographic Performance**
  - Orders and revenue by region/city
  - Heat map of sales concentration
- **Order Details**
  - Order status breakdown (delivered, returned, etc.)
  - Shipping and delivery timelines

---

##  Tools & Techniques

- **Microsoft Excel**
  - PivotTables and PivotCharts
  - Dynamic dashboards with slicers and dropdowns
  - Conditional formatting for KPIs
- **Power Query**
  - Data import, transformation, and cleaning
- **Formulas & Functions**
  - SUMIFS, IF statements, and more
